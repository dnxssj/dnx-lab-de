
# DNX Lab — Website

Corporate-style website for **DNX Lab**, built from the previous portfolio project.

## Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- React Router

## Positioning

The site is no longer structured as a personal portfolio. The public-facing brand is **DNX Lab**.

The main site focuses on:

- IT solutions
- Web development
- Smart Home
- Automation
- Individual software solutions
- Selected projects
- Project inquiries

Personal portfolio elements such as the About Me section, personal photo, GitHub activity and testimonials were removed.

The legally required personal information remains on the Impressum page.

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
